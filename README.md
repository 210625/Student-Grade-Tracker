# Student Grade Tracker

A simple console-based Java application for managing student grades. The project uses Object-Oriented Programming (OOP) and `ArrayList` to store and manage student records.

## Features

* Add student details
* Store student ID, name, and grade
* Display all student records
* Calculate average grade
* Find highest grade
* Find lowest grade
* Generate a summary report
* Menu-driven console interface

## Technologies Used

* Java
* Core Java
* OOP
* ArrayList
* Scanner
* Loops and Switch Case

## Project Structure

```text
StudentGradeTracker/
├── Main.java
├── Student.java
└── GradeManager.java
```

## How to Run

1. Install Java JDK.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Compile the files:

```bash
javac Main.java Student.java GradeManager.java
```

5. Run the program:

```bash
java Main
```
